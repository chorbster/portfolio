## Run locally

Clone the repository:

```bash
git clone https://github.com/chorbster/portfolio.git
cd portfolio
```

Open `index.html` in your browser. For live reload during development, you can also use VS Code's Live Server extension.

## Deploy

This repository is designed for **GitHub Pages**.

1. Push the site files to the `main` branch, with `index.html` at the repository root.
2. Open **Settings → Pages** in the GitHub repository.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Visit [the portfolio](https://chorbster.github.io/portfolio/) after deployment completes.
